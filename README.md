# 🌸 Dolce 7 Aroma — Repositorio Oficial

Bienvenido al repositorio del ecosistema digital de Dolce 7 Aroma. 
La tienda funciona bajo una arquitectura *Headless* (Frontend en GitHub Pages y Backend en Cloudflare Workers).

## 📚 Índice de Documentación

Para mantener este proyecto escalable y fácil de auditar, la documentación se ha dividido según su propósito en la carpeta `/docs`:

1. [⚙️ Arquitectura Técnica y Cálculos](docs/1_ARQUITECTURA_Y_CALCULOS.md)
   *Para desarrolladores, auditores de código y futuras integraciones de API (App externa).*
2. [📝 Bitácora de Versiones (Changelog)](docs/2_CHANGELOG.md)
   *Para rastrear qué funciones se añadieron, cuándo y por qué.*
3. [📖 Manual Operativo (Negocio)](docs/3_MANUAL_OPERATIVO.md)
   *Guía de uso sin código para gestionar inventario, anuncios, pedidos y administrar la tienda día a día.*
4. [🚀 Kit de Marketing y SEO](docs/4_MARKETING_Y_SEO.md)
   *Tácticas para crear enlaces estratégicos (deep links) y uso de palabras clave en campañas publicitarias.*
5. [🔧 Configuración Original y Despliegue](docs/0_CONFIG_ORIGINAL.md)
   *Manual técnico heredado sobre cómo se configuraron inicialmente Cloudflare, Resend, Telegram, GitHub Pages y el entorno local.*
